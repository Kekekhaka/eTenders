# Documentation index

## Cosmos project documents

- **IDEA_BRIEF.md** — the business case and scope (Stage 1).
- **REQUIREMENTS_PACK.md** — functional and non-functional requirements, user stories, acceptance criteria, process flow, traceability matrix (Stages 2–3).
- **DESIGN_SPEC.md** — system architecture, data model, API design, non-functional choices (Stage 4).
- **WORK_BREAKDOWN.md** — task decomposition, dependencies (Stage 5).
- **API_CONTRACT.md** — the data contract between pipeline and report; types, invariants, rendering rules (Stage 5).
- **IMPLEMENTATION.md** — high-level code outline, test strategy (Stage 5).
- **REVIEW_REPORT.md** — design review findings (Stage 6).
- **TEST_REPORT.md** — test coverage, results (Stage 7).
- **SECURITY_REPORT.md** — security review findings and mitigations (Stage 7).
- **DEPLOY_PLAN.md** — deployment steps, rollback, observability, operator checklist (Stage 8).
- **TEAM_LEADER_DECISIONS.md** — binding decisions from the delivery team (Stages 5–8).
